# Riverbay design assets

These are concept assets for the Riverbay direction (18 Oct 2026). The selected subset is now wired into the local app; see the App adoption section for the exact runtime copies in `public/assets/riverbay/`. The decisions behind them are in [../../DESIGN_DIRECTION.md](../../DESIGN_DIRECTION.md).

Figma board (source of the art, tokens and components): https://www.figma.com/design/sWzU2qGTd9poSxQzuC6z4E. The "Source artwork" frame holds the originals, the "Components" page holds the components, and the "Riverbay tokens" variable collection holds the tokens. An older, out-of-date copy exists at `pVGxVNMDSrP1fVBdZJhDwl`; do not use it.

## Layout

| Folder | Contents | Edit how |
|---|---|---|
| `source/` | Original generated rasters as downloaded from Figma: banner, mascot, animal sheet, botanical sheet, corner cluster, bottom border, and the beaver badge (rejected logo option A). The banner is also provided as WebP. | Do not edit in place. Replace a file with a new version under the same name, then rerun the build script. |
| `cutouts/characters/` | beaver, squirrel, bear with stacked beehive, rabbit with carrot; deer retained as reserve | Generated. Individual transparent PNG and WebP. |
| `cutouts/badges/` | Individual beaver, bear, squirrel and rabbit face badges on butter-yellow blobs | Generated PNG and WebP; edit/replace `source/badge-*.png` and rebuild. Beaver uses original `mark-option-a-beaver-badge.png`. |
| `cutouts/props/` | Individual daisy, stacked beehive, carrot and acorn, matching the characters' held objects | Generated transparent PNG and WebP from `source/prop-*.png`; source alpha preserved. |
| `cutouts/botanicals/` | willow-leaves, reeds, daisy, wildflowers, clover, leafy-sprig | Generated. |
| `cutouts/decor/` | corner-cluster, bottom-border | Generated. |
| `mark/` | Selected Tail & ripple mark (Option B) plus daisy-dot Nunito wordmark (Option C). Mark variants: full colour, small, on-dark, mono, mono-small. Wordmark and combined logo: light/dark. | Generated SVG. Edit `mark()` / `wordmark()` in `tools/build_assets.py` and rebuild. |
| `source/fonts/` | Nunito variable TTF and OFL licence from google/fonts (`ofl/nunito`), instantiated at weight 800 for outlined lettering. | Retain licence when distributing font sources. |
| `tokens/` | `riverbay-tokens.css` (`--rb-*` custom properties) and `riverbay-tokens.json` | Generated from the `TOKENS` table in the build script, which mirrors the Figma variables. |
| `rings/` | Four transparent SVG states: unassessed, beginning, developing, consistently-shown | Generated by `ring_asset()` in `tools/build_assets.py`, using ring colour tokens. |
| `tools/build_assets.py` | Rebuilds `cutouts/`, `mark/`, `tokens/` and `manifest.json` | See below. |
| `manifest.json` | Paths, pixel sizes and shortened SHA-256 hashes | Generated. |

Rebuild from the child repo root (needs Python with Pillow and fontTools):

```powershell
python -I docs/design-assets/riverbay/tools/build_assets.py docs/design-assets/riverbay/source docs/design-assets/riverbay
```

The script removes only the white background connected to an image's edges, so enclosed whites such as daisy petals survive. Sheets are split at empty vertical gaps. If a regenerated sheet has a different number of items, the script stops and reports it.

## Provenance and status

User selected a segmented ring reference: dashed outline for unassessed, then three thick rounded sectors filled cumulatively in one purple. Upper-left fills first, upper-right second, bottom third; remaining sectors use pale lavender. Small gaps remain in the completed ring. Flat SVG artwork; no image generation needed.
