# Class administration layout concepts

Generated with the built-in image tool. Fictional data only. A was selected for implementation. B (full-width index) and C (allocation board) remain potential future views. These images are layout studies; the implementation uses the real Riverbay logo and Phosphor icons.

- A: class directory with persistent class navigation and local Students / Teachers / Settings tabs.
- B: full-width class index; opening a class leads to its management page.
- C: class allocation board for comparing memberships across classes.

Recommendation: A for everyday administration; C could be a future allocation view. All three avoid floating white panels. Final implementation will use the real Riverbay logo and Phosphor action icons.
